# Watchdog Energy Management 4.4.1

## Fixes

- **No more "page can't be found" (HTTP 404) after deleting a meter.** If a meter is deleted, archived or restored when it no longer exists — for example because the button was pressed twice or the page was out of date — Watchdog now returns to the controller's channel list with a clear message instead of an error page. The first delete was always carried out correctly; no data was affected.
- **One click, one action.** After you confirm an action, its button is locked until the page reloads, so a double click or an extra Enter can no longer send the same request twice. This applies to every form in the program. Cancelling a confirmation keeps the button usable.

## Upgrade

No database changes. Install over 4.4.0 as usual, then press Ctrl+F5 once in each browser.
