# Watchdog Energy Management 4.6.1

## Fixes

- **Bulk-creating meter channels on a Modbus RTU or Modbus TCP/IP controller works again.** The page showed "The BacnetObjectType field is required." because the BACnet object type box is hidden for Modbus controllers but was still treated as required.
- **Optional boxes can be left empty.** Fields such as *Reason (optional)*, *First meter serial number*, and a shop's tenant, contact, floor, zone or notes were wrongly rejected when empty. Only fields that are really required (for example meter name, shop number, controller name) must be filled in.

## Upgrade

No database changes. Install over 4.6.0 as usual.
