# Watchdog Energy Management 4.6.3

## Improvements

- **Delete a shop.** Each row in Settings → Shops now has a red *Delete* button next to *Edit*. Deleting asks for confirmation and is recorded in the audit trail.
- **Safe by design.** A shop can be deleted only when it has no meters and no invoices. If it still has meters, the message tells you to move or delete them in Controller setup first. If it has invoices, they are kept as billing history and the message suggests setting the shop's status to Inactive or Vacant instead.
- **Meters column** on the shop list, so you can see at a glance which shops are empty.

## Upgrade

No database changes. Install over 4.6.2 as usual, then press Ctrl+F5 once in each browser.
