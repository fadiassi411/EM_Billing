# Watchdog Energy Management 4.7.1

## New: offset to match the meter display

Every Modbus and M-Bus meter now has an **Offset** (kWh, or m³ for water). Watchdog shows *device value × scaling factor + offset*, so a PLC or gateway that counts from 0 can show the same total as the meter's own display.

- On the meter's **Edit** page, the box *Offset — match the meter display* shows Watchdog's last reading. Type the number on the meter display into **Meter display now** and press **Calculate offset**, then save. The offset can also be typed directly and can be negative.
- **Never billed:** changing the offset starts a new counter on the next reading (like a meter replacement), so the difference is not charged on any invoice.
- The stored raw value is still the device's own number, and the meter list shows the offset next to the scaling factor.

BACnet meters are unchanged: they already have an offset on each BACnet point.

## Upgrade

The database gets one new meter setting (Offset, 0 for all existing meters), added automatically when the service starts. Install over 4.7.0 as usual, then press Ctrl+F5 once in each browser.
