# Watchdog Energy Management 4.5.0

## User levels you control

Settings → Users & access → **User levels & permissions** now shows a grid of checkboxes: one column per user level, one row per permission. Tick what each level may see or do and press **Save permissions**.

| Group | Permissions |
|---|---|
| Monitor | Dashboard · Meters (Grid, Generator, Water, meter details) · Invoices · Billing & operations page · Export readings |
| Billing | Tariffs & billing cycle · Billing runs & preview · Record payments · Email invoices |
| Control | Counter review · Shops · Controllers & meters |
| Settings | Invoice email settings · System features · License · Audit trail · Backup & restore |

- **Create your own levels** (for example Technician or Accountant), empty or starting from another level's permissions. Levels you created can be deleted when no user has them.
- **Administrator always has every permission** and is the only level that manages users and levels, so nobody can give themselves more rights.
- Ticking an action also ticks the page it is on (for example *Record payments* also gives the *Billing & operations page*).
- Changes apply on the user's next click; nobody needs to sign out. A changed user level reaches signed-in users within a minute.
- The menu shows each user only what their level allows; other pages show a clear "Not allowed for your level" message. A level without the Dashboard opens on its first allowed page.
- Every change to a level is recorded in the Audit trail.

## Upgrade

The existing levels keep exactly the rights they had: Billing Manager (billing, tariffs, payments, invoice email, readings export), Operator (monitoring, Billing & operations page, readings export) and Viewer (dashboard, meters, invoices). No database structure changes; permissions are stored with the existing user levels. Install over 4.4.1 as usual, then press Ctrl+F5 once in each browser.
