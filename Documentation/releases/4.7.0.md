# Watchdog Energy Management 4.7.0

## New: M-Bus meters

Watchdog can now read wired M-Bus meters (electricity, heat and water) through an **M-Bus to Ethernet gateway** in transparent TCP mode.

- **New controller type:** Controller setup → Add controller → *M-Bus via Ethernet gateway (TCP)*. Enter the gateway IP address and TCP port (often 10001).
- **Addressing:** each meter uses its M-Bus **primary address** (1–250) or its 8-digit **secondary address (ID)** from the meter label. Use the ID when several meters share the same primary address.
- **Automatic billing value:** electricity and heat meters bill the current energy total (kWh); water meters bill the current volume total (m³). MWh, GJ, Wh and litres are converted automatically. A different record can be chosen per meter.
- **Read meter** button on the meter page: shows the meter's ID, manufacturer, medium and every value it reports, and marks the one that will be billed.
- **One silent meter does not stop the others:** it is marked Failed, and the rest of the bus is still read.
- Counter review, history, dashboard cards and invoices work exactly as for Modbus and BACnet meters.

See the M-Bus commissioning guide (Documentation/MBus-commissioning.md) for gateway settings and step-by-step setup.

Not included: wireless M-Bus, encrypted meter data, and records sent in a second telegram.

## Upgrade

The database gets two new meter settings, added automatically when the service starts. Install over 4.6.3 as usual, then press Ctrl+F5 once in each browser.
