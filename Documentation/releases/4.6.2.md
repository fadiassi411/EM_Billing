# Watchdog Energy Management 4.6.2

## Improvements

- **Tidier meter channel actions.** Each meter row in Controller setup → meter channels now has one row of compact outlined buttons — Edit, Points (BACnet), Archive / Restore and Delete (red) — with a tooltip on each. Words appear next to the icons on very wide screens. The status column is shown as a coloured label.
- **Backup & restore has its own page** (Settings → Backup & restore) and is no longer part of Billing & operations. The page has a Rows selector (10, 25, 50, 100, All), search, a Type column (Automatic, Manual, Safety copy) with filter buttons, and *Create backup now*. Restore still checks the backup and saves a safety copy of the current data first.
- **Card colour legend** on the dashboard: Grid, Generator, Water, Not in service, Alarm, Waiting. Grey cards are meters that are not active or not commissioned yet.

## Fixes

- **License page:** the *Remove license* button was invisible (red text on a red background). It is now a clear outlined button with a short explanation. The license file picker is tidier.

## Upgrade

No database changes. Install over 4.6.1 as usual, then press Ctrl+F5 once in each browser.
